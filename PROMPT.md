# Project brief

Create a self-contained, responsive, static HTML investment dashboard demo called Portfolio Studio.

Requirements:
- Use only fictional sample data totaling exactly $10,000.
- Never include personal, household, brokerage, bank, or other real financial information.
- Do not connect to Monarch, MCP, brokerage APIs, or any external service.
- Make no network requests and use no tracking scripts.
- Include overview, cash accounts, accounts, holdings, allocation, history, and methodology sections.
- Include a searchable account table and CSV exports; all exported values must also be fictional.
- Explain that values are illustrative, static, and not investment advice.
- Keep the result usable by opening index.html directly in a modern browser.
