# Portfolio Studio — Fictional Investment Dashboard Demo

A standalone, browser-based demo of a consolidated investment dashboard built to illustrate a ChatGPT + Monarch MCP workflow.

## Public demo

Once GitHub Pages is enabled and `index.html` is added, the site will be available at:

`https://vighnesh.github.io/investment-dashboard-demo/`

## Important: fictional data only

This public demo is intentionally separate from any real household portfolio. Every account, institution, holding, balance, return, and date is invented. The sample portfolio totals exactly **$10,000.00**. No real financial accounts are connected, and the page makes no network requests.

## Features

- Overview of sample assets and account groups
- Cash accounts, account inventory, and holdings tables
- Look-through allocation illustration
- Searchable account list
- CSV exports containing fictional sample data
- Responsive layout and keyboard focus styling
- Methodology and limitations notes

## Run locally

Open `index.html` in any modern browser. No build step or dependencies are required.

## Hosting

This is a static HTML site. Enable GitHub Pages for the `main` branch using the repository root as the publishing source, or use the included GitHub Actions workflow.

## Disclaimer

For demonstration and educational purposes only. Not investment advice. The data is synthetic and does not represent actual accounts or securities.
